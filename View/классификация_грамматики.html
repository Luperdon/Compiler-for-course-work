Тип 3
Регулярная грамматика
(Right-Linear Regular Grammar)

📋 Обоснование принадлежности к регулярному типу

  • ✓ Левая часть содержит ровно один нетерминальный символ
    Все правила имеют вид A → ..., где A — одиночный нетерминал. Пример: <IDREM> → Symbols <IDREM>
  • ✓ Правила имеют строго ограниченную форму (главный признак)
    Только праволинейные правила вида A → aB и терминальные правила вида A → a.
    Отсутствуют правила вида A → Ba (леволинейные).
  • ✓ Отсутствуют правила с двумя нетерминалами в правой части
    Нет правил вида A → B C или A → a B C. Каждое правило содержит не более одного нетерминала, и он всегда находится в конце.
  • ✓ Рекурсия только праволинейная (хвостовая)
    Допустима только рекурсия вида A → a A. Пример: <INTREM> → digit <INTREM>
  • ✓ Применение правил не зависит от контекста
    Правило можно применить всегда, независимо от окружающих символов.

⚙️ Характеристики грамматики

📌 Регулярная (тип 3) Соответствует классу регулярных грамматик по иерархии Хомского
➡️ Праволинейная Нетерминал всегда находится в конце правой части правил: A → aB
🎯 Детерминированная Для каждой пары (состояние, входной символ) определён не более одного перехода
🔍 LL(1)-грамматика Возможно построение LL(1)-анализатора (чтение слева направо, один символ вперед)
🚫 Не леворекурсивная Отсутствуют правила вида A → Aα (левая рекурсия)
🤖 Распознаётся конечным автоматом Для синтаксического анализа достаточно конечного автомата без магазинной памяти

✅ Вывод

Разработанная грамматика относится к регулярному типу (тип 3) по классификации Хомского, так как:

  • Все правила имеют вид A → aB или A → a
  • Отсутствуют правила с двумя нетерминалами в правой части
  • Рекурсия допускается только праволинейная (хвостовая)
  • Грамматика может быть распознана конечным автоматом

📌 Важно: Регулярная грамматика (тип 3) является подмножеством контекстно-свободных грамматик (тип 2), но имеет более строгие ограничения на форму правил, что позволяет использовать для её распознавания конечный автомат вместо магазинного.
