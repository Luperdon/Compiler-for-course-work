📖 Текст (справочная информация)

Открывает HTML-страницы с теоретическими материалами:

  • Постановка задачи — описание целей и требований
  • Грамматика — формальное описание языка
  • Классификация грамматики — тип грамматики по Хомскому
  • Метод анализа — описание алгоритма рекурсивного спуска
  • Диагностика и нейтрализация ошибок — алгоритм Айронса
  • Тестовый пример — демонстрация работы анализатора
  • Список литературы — использованные источники
  • Исходный код программы — код лексера и парсера

❓ Как пользоваться программой

  1. Ввод кода: Напишите или вставьте код в окно редактирования. Поддерживается синтаксис: идентификатор = "строка {:f}".format(число);
  2. Запуск анализа: Нажмите кнопку Пуск или клавишу F5.
  3. Просмотр результатов: В таблице ниже отобразятся все найденные ошибки с указанием строки и позиции.
  4. Работа с файлами: Используйте меню Файл или кнопки на панели инструментов для сохранения и загрузки кода.
  5. Редактирование: Стандартные операции (копировать, вставить, отменить) доступны через меню Правка, кнопки или горячие клавиши.
  6. Справочная информация: Для изучения теории откройте раздел Текст в меню.
⚠️ Примечание: Каждый оператор должен заканчиваться точкой с запятой ;. Форматный спецификатор внутри строки должен быть записан как {:f}.
