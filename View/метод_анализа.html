📌 Общие сведения

Для реализации синтаксического анализа используется метод конечного автомата. Этот метод основан на формальной модели распознавателя, которая последовательно читает входную строку и выполняет переходы между состояниями в зависимости от текущего входного символа (лексемы).


Преимущества метода:

  • Простота реализации и понимания
  • Высокая скорость работы (линейная сложность O(n))
  • Возможность точной диагностики ошибок с указанием позиции
  • Лёгкость добавления новых правил и состояний
  • Детерминированность — однозначность переходов

📐 Формальное определение конечного автомата

M = (Q, Σ, δ, q₀, F)

где:
• Q — конечное множество состояний
• Σ — входной алфавит (множество допустимых лексем)
• δ — функция переходов: Q × Σ → Q
• q₀ — начальное состояние (q₀ ∈ Q)
• F — множество конечных (допускающих) состояний (F ⊆ Q)

📚 Множества автомата

🔷 Q — Множество состояний:

Start IdRem AfterEqual OpenQuote OpenBrace Colon LetterF CloseBrace CloseQuote AfterDot Format OpenArg InNumber AfterNumber CloseArg End Error

🔤 Σ — Входной алфавит (лексемы):

id = " { : f } . format ( число ) ;

🎯 q₀ — Начальное состояние:

q₀ = Start

🏁 F — Конечные состояния:

F = {End}

⚙️ Алгоритм синтаксического анализа

Шаг 1. Инициализация
currentState = Start, position = 0
Шаг 2. Чтение лексемы
currentLexem = lexems[position]
Шаг 3. Проверка допустимости
Если для текущего состояния и лексемы определён переход:
  → выполнить переход в новое состояние
Иначе:
  → зафиксировать синтаксическую ошибку
  → применить стратегию нейтрализации (метод Айронса)
Шаг 4. Продолжение
position++, переход к шагу 2
Шаг 5. Завершение
Если достигнуто состояние End и все лексемы обработаны → успех
Иначе → ошибка

📝 Псевдокод алгоритма:

function Parse(lexems): boolean
{
    currentState = Start;
    position = 0;
    
    while (position < lexems.length) {
        currentLexem = lexems[position];
        
        switch (currentState) {
            case Start:
                if (currentLexem.type == IDENTIFIER)
                    currentState = IdRem;
                else
                    Error("Ожидался идентификатор");
                break;
            // ... остальные состояния
        }
        position++;
    }
    
    return (currentState == End);
}

🛡️ Нейтрализация синтаксических ошибок (метод Айронса)

Для восстановления после синтаксических ошибок используется метод Айронса (panic mode recovery). Этот метод позволяет продолжить анализ после обнаружения ошибки и найти все ошибки в программе за один проход.

Стратегии нейтрализации:

Стратегия 1: Пропуск лексемы

Недопустимый символ удаляется из потока, анализ продолжается со следующей лексемы.

Пример: * → пропуск
Стратегия 2: Вставка лексемы

В поток вставляется ожидаемый символ, анализ продолжается.

Пример: format → вставка . перед format
Стратегия 3: Замена лексемы

Ошибочный символ заменяется на ожидаемый.

Пример: {:g} → замена на {:f}
Стратегия 4: Синхронизация

Поиск синхронизирующего символа (например, ';') для перехода в безопасное состояние.

Пример: поиск ; после ошибки

Алгоритм обработки ошибки:

function HandleError(state, lexem)
{
    errorCode = DetermineErrorCode(state, lexem);
    
    switch (errorCode) {
        case SKIP:
            // пропустить лексему
            position++;
            break;
        case INSERT:
            // вставить ожидаемую лексему
            currentState = expectedState;
            break;
        case REPLACE:
            // заменить лексему
            currentState = expectedState;
            position++;
            break;
        case SYNC:
            // найти синхронизирующее состояние
            while (position < lexems.length)
                if (lexems[position].type == SYNC_SYMBOL)
                    break;
                else
                    position++;
            currentState = Start;
            break;
    }
}

✅ Вывод

Реализованный метод синтаксического анализа на основе конечного автомата обеспечивает:

  • Детерминированность — для каждой пары (состояние, лексема) определён не более одного перехода
  • Линейную сложность O(n) — анализ выполняется за один проход по лексемам
  • Точную диагностику — указание позиции и описание каждой ошибки
  • Восстановление после ошибок — метод Айронса позволяет найти все ошибки в программе
  • Простоту реализации — конечный автомат легко реализуется с помощью оператора switch/case

Данный метод успешно применяется в разработанном синтаксическом анализаторе и показывает корректные результаты на всех тестовых примерах.
