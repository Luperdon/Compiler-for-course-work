🎯 Цель работы

Разработать лексический и синтаксический анализатор для конструкции форматированного вывода в языке Python.

📝 Описание конструкции

идентификатор = "{:f}".format(число);

✅ Примеры корректных строк

float_format = "{:f}".format(3.234e+4);
result = "{:f}".format(-123.456);
temp = "{:f}".format(0.001e-5);

❌ Примеры строк с ошибками

float_form*at = "{:f}".format(3.234e+4); недопустимый символ
result = "{:g}".format(-123.456); неверный спецификатор
x = "{:f}".format(5) отсутствует ';'

📋 Требования к анализатору

  • Выделять лексемы из входной строки
  • Классифицировать лексемы по типам
  • Проверять синтаксическую корректность
  • Обнаруживать и сообщать об ошибках
  • Указывать позиции ошибок
  • Обеспечивать навигацию по ошибкам
