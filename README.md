## 2. Вариант задания

### 2.1. Язык программирования

В качестве входного языка используется **язык арифметических выражений** с целочисленными литералами, идентификаторами и операциями:

- **Бинарные операторы:**
  - `+` — сложение
  - `-` — вычитание
  - `*` — умножение
  - `/` — целочисленное деление
  - `//` — целочисленное деление (синоним `/`)
  - `%` — остаток от деления
  - `**` — возведение в степень (левоассоциативное в реализации)

- **Операнды:**
  - Целые числа (например, `0`, `123`, `4567`)
  - Идентификаторы (последовательности букв латинского алфавита, цифр и символа подчёркивания, начинающиеся с буквы или `_`)

- **Скобки:** `(` и `)` для изменения приоритета операций.

### 2.2. Полное определение КС-грамматики

Грамматика **G** для арифметических выражений (после устранения левой рекурсии):
E → T A
A → ('+' | '-') T A | ε
T → F B
B → ('*' | '/' | '//' | '%' | '**') F B | ε
F → число | идентификатор | '(' E ')'

**Терминалы:**
- `число` — целочисленная константа (последовательность цифр)
- `идентификатор` — буквенно-цифровая последовательность, начинающаяся с буквы или `_`
- `'+', '-', '*', '/', '//', '%', '**'` — знаки операций
- `'('` и `')'` — скобки

**Нетерминалы:**
- `E` — выражение (expression)
- `A` — хвост сложения/вычитания (additive tail)
- `T` — терм (term)
- `B` — хвост умножения/деления (multiplicative tail)
- `F` — фактор (factor)

### 2.3. Примеры верных строк (корректных выражений)

| № | Входная строка | Пояснение |
|---|----------------|-----------|
| 1 | `2 + 3` | Простое сложение |
| 2 | `15 * 4 - 2` | Смешанные операции с учётом приоритета |
| 3 | `(1 + 2) * 3` | Изменение приоритета с помощью скобок |
| 4 | `a + b * c` | Выражение с идентификаторами |
| 5 | `10 // 3` | Целочисленное деление |

| 7 | `2 ** 3 ** 2` | Возведение в степень (левоассоциативно) |
| 8 | `((2 + 3) * (4 - 1)) / 2` | Вложенные скобки |
| 9 | `_var123 + 42` | Идентификатор с подчёркиванием в начале |
| 10 | `(a+b)*(c-d)` | Выражение без пробелов |

## 5. ПОЛИЗ (Обратная польская запись)

ПОЛИЗ (польская инверсная запись) — форма записи выражений, в которой операторы следуют за операндами. Вычисление ПОЛИЗа выполняется с использованием стека.

### 5.1. Преобразование в ПОЛИЗ (алгоритм Дейкстры — сортировочная станция)

**Пример для выражения:** `2 + 3 * 4`

**Результат ПОЛИЗА:** `2 3 4 * +`
<img width="1286" height="314" alt="image" src="https://github.com/user-attachments/assets/fa344c96-1dcb-438c-937f-f0b710e63afb" />

### 5.2. Вычисление ПОЛИЗа

**Вычисление на стеке для `2 3 4 * +`:**

| Шаг | Токен | Стек | Действие |
|-----|-------|------|----------|
| 1 | `2` | `[2]` | push(2) |
| 2 | `3` | `[2, 3]` | push(3) |
| 3 | `4` | `[2, 3, 4]` | push(4) |
| 4 | `*` | `[2, 12]` | pop(4), pop(3), 3*4=12, push(12) |
| 5 | `+` | `[14]` | pop(12), pop(2), 2+12=14, push(14) |

**Результат вычисления:** `14`
